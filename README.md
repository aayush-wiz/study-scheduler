# Study Scheduler

A modern, Notion-inspired study scheduling application built with Next.js and TypeScript. This application helps students efficiently manage their study time by automatically generating optimized study schedules based on course difficulty, priority, and deadlines.

## Features

- 🎯 Smart schedule generation based on multiple factors:
  - Course difficulty (Easy, Medium, Hard)
  - Priority levels (Low, Medium, High)
  - Deadlines
  - Available study hours
- ⏰ Pomodoro mode support
- 📊 Progress tracking for each course
- 🔄 Automatic break time calculations
- 💾 Local storage for data persistence
- 🎨 Clean, Notion-inspired UI
- 📱 Responsive design

## Tech Stack

- Next.js 13+ (App Router)
- TypeScript
- Tailwind CSS
- Context API for state management
- LocalStorage for data persistence

## Getting Started

### Prerequisites

- Node.js 16.8 or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone [your-repo-url](https://github.com/aayush-wiz/study-scheduler.git)
cd study-scheduler
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
